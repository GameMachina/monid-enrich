# Contributing to Monid Enrich

Thanks for helping improve Monid Enrich. Report bugs and feature ideas in the [project issue tracker](https://github.com/GameMachina/monid-enrich/issues).

When reporting a problem, include the steps to reproduce it, what you expected, what happened, and your app version, browser, and Node version where relevant. Synthetic examples are best.

Never include API keys, session cookies, database URLs, MCP keys, real customer records, or unredacted network traces. Report security vulnerabilities privately using [SECURITY.md](SECURITY.md).

For local setup and architecture, see the [README](README.md#self-host-in-5-minutes) and [development guide](docs/development.md).
